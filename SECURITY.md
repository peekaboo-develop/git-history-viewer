# Security policy

Please report vulnerabilities through [GitHub Private Vulnerability Reporting](https://github.com/peekaboo-develop/git-history-viewer/security/advisories/new). Do not open a public issue for suspected security vulnerabilities.

The supported security boundary is a local, loopback-only Web server and a local stdio MCP process fixed to one repository. Remote HTTP MCP and Git mutation commands are intentionally unsupported.
